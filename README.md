# Sudoku Game using Python

## About

A simple Sudoku game implemented in Python using Tkinter. Features include a 9×9 grid, number pad for input, hints, pencil mode, undo/redo functionality, and an in-game timer. The game generates unique puzzles with adjustable difficulty levels. It runs as a single Python file requiring only Python 3.x with no additional libraries needed.

## Features

- 9×9 Sudoku grid interface  
- Number pad for easy input  
- Hints to assist solving  
- Pencil mode for tentative entries  
- Undo and redo moves  
- Timer to track game duration  
- Puzzle generation with adjustable difficulty
